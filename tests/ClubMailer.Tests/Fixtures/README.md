# Fixtures de test (MOCKS)

Tous les fichiers de ce dossier sont des **mocks** : des données entièrement inventées,
sans aucun lien avec le vrai export d'inscriptions ni avec une vraie personne.

- Noms `MOCKNOMn`, emails en `@example.com` (domaine réservé aux exemples), licences `000000n`, club `CLUB MOCK`.
- Ne jamais y copier, même modifié, un extrait du vrai export (RGPD : dépôt public).
- `format_a_valide.csv` : format A (séparateur `;`, UTF-8 avec BOM, fins de ligne LF), 3 inscriptions.
